# Bank System

![Language](https://img.shields.io/badge/Language-C++-00599C?style=for-the-badge&logo=c%2B%2B&logoColor=white)

A C++ console application for managing a banking system.

## Features
- Banking system console operations

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/OmarAlfar0uk/Bank_System.git
   ```
2. Open the project in your preferred C++ IDE (e.g., Visual Studio, CLion) or compile using g++:
   ```bash
   g++ -o bank_system main.cpp
   ./bank_system
   ```
